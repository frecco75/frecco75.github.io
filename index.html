J'ai commencé sur les tunnels de paiement de Rakuten France, puis j'ai construit des sites de voyage pour Promovacances et ses partenaires. Chez Publicis Sapient, j'ai pris le rôle de tech lead sur la refonte du Drive Intermarché, avant de rejoindre le programme de transformation digitale des Galeries Lafayette.

Freelance depuis 2020, j'interviens comme lead developer, architecte ou coach craft : socles techniques partagés, architecture hexagonale, programmation fonctionnelle, contract first. Je travaille aujourd'hui chez BlaBlaCar, sur le backend du covoiturage.

L'IA fait désormais partie de mon métier : j'utilise des assistants de code IA au quotidien, avec les mêmes exigences que pour le reste du code (tests, revue, architecture lisible).

En parallèle, je construis une plateforme tech pilotée par l'IA : une DSI dont les rôles sont tenus par 24 agents spécialisés.

Ce qui me motive : transmettre. Tech talks, pair et mob programming, revues de code et accompagnement de profils juniors font partie de toutes mes missions.
